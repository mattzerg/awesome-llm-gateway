# Contributing

Additions and corrections are welcome. Open a pull request that:

1. **Fits the scope** — LLM gateways, proxies, routers, or the observability tooling used with them. General LLM tools belong in [awesome-llm](https://github.com/Hannibal046/Awesome-LLM) instead.
2. **Is one line** — `[Name](link) — what it is, factually, in one sentence.` No superlatives, no marketing adjectives, no pricing claims about third parties.
3. **Keeps alphabetical order** within its section.
4. **Points at something maintained** — the project should have activity within the last year, or be a paper/reference of lasting value.

Removals are contributions too: if a project is abandoned or a link is dead, open a PR.

Vendors may add their own products. Disclose the affiliation in the PR description; the entry itself must read as neutrally as every other line.
